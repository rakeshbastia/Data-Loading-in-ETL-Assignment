# Data Loading in ETL – Assignment

## About the Assignment

This repository contains my assignment on **Data Loading in ETL**.

The assignment focuses on the checks and processes that should be completed before loading data into a database. It covers data quality issues, primary key validation, missing values, data type validation, date format consistency, load readiness, pre-load validation, cleaning strategy, loading strategy, and the impact of poor data quality on BI dashboards.

## Assignment Topics

1. Data Understanding
2. Primary Key Validation
3. Missing Value Analysis
4. Data Type Validation
5. Date Format Consistency
6. Load Readiness Decision
7. Pre-Load Validation Checklist
8. Cleaning Strategy
9. Loading Strategy Selection
10. BI Impact Scenario
